# Jasama Transition-to-Command Matrix

Status: explicit technical mapping of the state catalogs in `STATE_MACHINES.md`. This document does not enable a decision-gated transition.

The matrix has exactly one row for each documented allowed `(machine, from, to)` pair. “Prior active state” is the single documented recovery destination in the Pesanan catalog. Creation rows are not state-to-state pairs and are covered by aggregate-creation commands in `API_EVENTS_AND_JOBS.md`.

The Pesanan `pending_confirmation → pending_confirmation` row is a changed-terms acceptance: the Mitra proposes a new immutable pending terms version, the Pemesan explicitly accepts that exact version, and the transaction replaces the 12-hour/24-hour jobs with the new expected terms version. A reminder never changes state.
